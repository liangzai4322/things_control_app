# TaskBox 核心功能与业务规则

最后核对：2026-08-10。

TaskBox 是一套以人生参谋部为决策入口、以盒子为执行入口的个人行动系统。核心闭环是：参谋部确定方向并派发行动，任务进入合适盒子，按日期与主线推进，完成证据返回复盘与参谋部；完成记录同时进入可追溯历史并结算积分，积分再用于兑换奖励。放松池、清单、小世界和弑神塔承担不同于待办的用途。

## 1. 首页与盒子

- “思路盒 / 灵感盒 / 想法盒”属于构思缓冲区。重要盒和待办盒中的任务可以通过右键菜单“送回思路盒”，想清楚后再移回执行盒。
- 自动拉取会识别旧版本遗留的本地独有思路盒，将盒子及其内容补传到服务器；服务器盒子 ID 是跨页面合并时的唯一身份。
- `交给 AI` 的任务使用独立蓝紫光带、渐变标签和 `✦` 标记，并在盒子详情、日期议程和主线页保持一致。
- 首页顶部工具区提供 `✦` AI 识别入口，与底部快捷按钮使用同一识别流程。

- 首页显示重要、待办、放松、思路等核心盒子，也允许创建自定义盒子。
- 重要盒和待办盒固定在前两位；其他盒子可删除、排序或置顶。
- 手机保持双列信息密度，桌面端利用更宽视口展示更多盒子和任务信息。
- 核心盒导航在首页、盒子详情、积分、小世界和主线页保持一致；详情页不重复显示当前盒子。
- 每个盒子有独立名称、主题色、图标、类型、介绍文案和“每日一句”。每日一句可直接点击编辑并同步到服务器。
- 首页提供日期视图，集中查看今日新增、计划任务、逾期任务和已完成任务。

## 2. 盒子类型

盒子不是都等于待办。创建后仍可修改类型，但修改前需要确认。

| 类型 | 用途 | 核心行为 |
| --- | --- | --- |
| 任务盒 | 重要、待办等需要推进和完成的事项 | 计划、截止、进度、完成、积分、周期任务、置顶 |
| 放松池 | 放松活动、奖励候选、惩罚候选 | 抽取、使用记录、冷却时间、积分成本 |
| 清单盒 | 灵感、资料、备忘、长期收藏 | 收藏、标签、链接、归档，不计入待办完成率 |

思路盒内容可以移动到重要盒或待办盒；重要盒和待办盒之间也可以通过任务菜单互相迁移。

## 3. 任务生命周期

- 新建或编辑任务时可选择“普通 / 列表第 1 / 第 2 / 第 3”，默认普通；该选择写入 `pinLevel`，与 P0–P3 任务重要程度相互独立。
- 保存动作带提交锁，避免双击或快捷键与点击同时触发造成重复创建。
- 同一盒子、相同内容与相同时间语义、且创建时间接近的不同 ID 记录会合并为一个展示项；别名 ID 会随主记录一起更新和删除，避免副本复活。间隔较久或计划日期不同的同名任务仍保留为独立任务。

- 任务字段包括内容、盒子、优先级、计划时间、截止时间、积分、进度、置顶档位、备注、主线、支线和里程碑关联。
- 执行方式独立于设备场景，分为“我来做”“交给 AI”“人机协作”。AI 任务仍可设置在哪个设备查看，列表使用独立标签标识，周期实例继承执行方式。
- 任务可标记为电脑、手机或通用。旧任务迁移为通用，新任务默认电脑；自动场景优先显示当前设备任务，也可手动切换为手机、电脑或全部。
- 非当前设备任务不被删除或彻底隐藏，在盒子详情的“其他设备任务”折叠区中保留访问入口。
- 跨天任务可从右键或移动端三点菜单选择“今天收工”，保存当前进度、续接备注和再次出现时间；默认次日 08:00 回到列表。
- 单次任务计划到未来日期时，盒子当前任务区不会提前显示；它在计划日 00:00 自动释放，在此之前可从“待到点出现”和日期页对应日期查看、编辑。
- “今日已收工”默认折叠，可提前选择“继续显示”；如果再次出现时间晚于截止时间，保存前会明确提示。
- 截止时间精确到小时和分钟；到期后整条任务进入危险红色状态。
- 重要盒置顶只有第一、第二、第三三个档位，右键菜单通过可视化选择器设置。
- 任务支持右键菜单和移动端操作入口，可编辑、删除、置顶、迁移盒子。
- 删除进入默认折叠的“已删除”，不会立即物理移除；可还原误删内容。
- 已完成按时间倒序分组：一周内按天，一周以外归入“一周以前”，越早完成越靠下。
- 完成和删除使用稳定记录 ID；同一条任务的重复视图不得产生重复记录或级联误删。
- 保存编辑支持 `Ctrl+Enter`。
- 任务完成后自动打开“完成回执”，从留白焦点、冲线时刻、像素通关、纸页档案、声波庆典、赛道编号、灵感拼贴、思考手记 8 款模板中随机选择一款；回执以备注为主体，包含完成时间、盒子、主线/支线和积分。长备注自动拆页且整组保持同款，可主动换款、保存 PNG 或调用手机系统分享。
- 已完成列表保留回执入口。完成快照不跟随之后的任务编辑自动改变；需要时由用户主动按最新内容重新生成。

## 4. 日期与周期任务

- 日期页提供今天、今晚、明天等快捷计划与截止时间。
- “今天”的计划时间按当前时间向上取整后加两小时；“今天截止”默认当日 22:00，“今晚截止”默认次日 00:00。
- 周期支持每天、间隔若干天、每周、每月，并可暂停、修改整个系列或删除整个系列。
- 周期模板不作为普通任务显示；系统以 `recurrenceKey` 保证同一周期实例唯一。
- 每个周期规则有独立出现时间，默认 08:00。完成当前实例后可以预生成下一实例，但在 `visibleAfter` 到达前只进入“待到点出现”，不会混入盒子当前任务和今日统计；日期页对应日期仍可提前查看。
- 完成周期实例后，下一实例按规则生成，完成历史仍保留；每天、间隔日、每周和每月共用同一释放机制。

## 5. 主线、支线与里程碑

- 同时推进的活跃主线建议控制在 2 至 6 条，系统上限为 6 条；最多两条可标记“本周重点”。
- 主线记录最终成果、当前阶段、状态、目标日期、识别色和排序；创建时提供 8 组独立于盒子主题色的矿物色识别方案。
- 每条主线可建立多条支线项目，例如旅行、实验、成长、关系或生活体验；同一主线同时推进的非暂停支线最多 6 条，完成和放弃的支线不占名额。
- 支线状态为构思中、待启动、进行中、待收尾、已完成、已暂停或已放弃；记录原因、完成标准、下一步、日期、颜色和复盘。
- 首页显示主线概览；`#mainline/:id` 页面显示下一行动、支线、里程碑和关联任务，`#branch/:id` 是可独立打开和完成的支线详情页。
- 任务可关联主线、支线与具体里程碑。任务选择支线时主线必须与支线所属主线一致；周期任务及其实例继承支线。
- 完成支线不会自动完成主线。存在未完成任务时，可选择保留支线关联，或只释放支线关联并让任务留在原盒子。
- 删除支线只解除任务的支线关联；删除主线会删除其支线与里程碑，并解除任务关联，不删除任务本身。

## 6. 积分与奖励

- 积分账户由流水计算，不把余额当作不可追溯的独立数字。
- 完成任务自动产生收入流水；取消完成或调整任务分值时会对账修正。
- 支持历史积分补录、手动记账、AI 文本识别后人工确认入账。
- 奖励池支持新增、修改、启停和兑换；兑换成功产生支出流水。
- 积分页面展示余额、近期变化、规则、奖励和流水。
- 积分数据通过同一服务器 API 读写，失败时先保留本地数据并在后续操作重试。

## 7. 小世界

- 珍宝阁和弑神塔是独立的游戏化内容库，不算待办任务。
- 两者按层级和记录读取，支持新增、修改、删除和完成状态。
- 弑神塔可快速跳层；抽奖转盘显示候选内容和结果。
- 外部服务配置集中在小世界设置中。

## 8. 同步、离线与认证

- 唯一正式云端数据源是自建服务器上的 SQLite API，Gist 已退出运行链路。
- 页面启动时用本地缓存快速首屏，再拉取服务器快照并立即刷新当前路由。
- 新增、修改、删除按记录调用 API，不上传整份 JSON。
- 拉取前等待记录级写入队列稳定；同`id / syncKey / recurrenceKey`的云端任务（含删除 tombstone）覆盖旧浏览器副本，本地独有离线任务继续保留。
- API Token 仅保存在当前浏览器本地；填写后立即拉取盒子、积分和小世界数据。
- 设备场景偏好同样是当前浏览器的本地设置，手机和电脑可以分别保持自己的模式。
- 云端请求失败时保留本地缓存和待同步操作，后续写操作继续重试。
- 待同步操作保存在浏览器持久化 outbox，重载后仍在；恢复连接时先按原顺序重放，outbox 未清空前不允许云端整库快照覆盖本地事实。
- 同步提示只在远端内容确有变化或写入成功时出现，不能每次刷新都误报。

## 9. 数据安全与恢复

- 线上只部署 `dist/` 压缩产物，不部署源码映射。
- Token、服务器密码、Cookie 和原始认证头不得写入仓库、文档、日志或静态构建。
- 前端发布前保留 Git 标签或本地压缩备份；服务器变更前备份数据库和 API 目录。
- SQLite 开启 WAL；服务端写入以记录 ID 幂等更新，避免整文件覆盖和重复导入。

## 10. 人生参谋部 MVP

- 无 Hash 访问默认进入 `#hq`；人生参谋部是主面板，盒子首页 `#home` 是执行副面板。
- 所有页面顶部保留“参谋部 / 盒子”指挥切换器，切换主副面板时不改变两边各自的数据职责。
- 首页“参”按钮仍可进入 `#hq`，桌面端显示宽屏指挥台，手机端保持单列执行阅读。
- 今日驾驶舱坚持 `1 个唯一主动作 + 最多 2 个维护动作`，不把三个任务伪装成同等重要。
- 编辑今日驾驶舱会把选中的动作派发到盒子前三位，同时写入独立承诺字段。
- 停止做、继续保持、五项外部结果和昨日承诺闭环按日期存入云端。
- 项目中心复用主线和任务，自动标记推进中、停滞、阻塞和缺少下一步。
- 待决策队列只处理继续、排期、拆小或停止等取舍，不代替普通待办。
- 系统接入口第一版接通日省、主线系统和行动盒子，并为交易、镜像和 GAP 教练保留扩展位。
- 日省同步脚本根据完整 Markdown 关联或创建次日承诺，避免同内容未完成任务重复生成。
- 日省运行前自动生成服务器事实包；驾驶舱的日省闭环卡展示当日同步状态、完成/进度计数和最近 7 天唯一承诺趋势。
- 顶部时间尺度可在今日、本周、本月之间切换：周省写入唯一实验和主瓶颈，月省写入业务组合、战略决策和三层目标。
- 日省、周省、月省都先读取人生参谋部事实包、完成后幂等回写；月目标不会直接批量变成普通任务。
- 参谋部主动作和维护动作使用 `#box/:boxId/:taskId/hq-primary|hq-maintenance` 精确下钻；第四段保留任务角色，盒子自动展开、定位并高亮目标任务。
- 从参谋部进入盒子时显示“本周实验 → 所属项目 → 当前任务角色”的指挥链，支持返回参谋部或进入项目；任务卡同时保留参谋部角色标识。

## 11. 任务中枢外部写入

- 任务中枢是日省前置的确认与分发层，不是第二套任务库。所有外部任务先写`daily_action_proposal`；获批后仅通过`POST /v1/hq/proposals/:id/promote`幂等创建或关联 TaskBox，禁止直调任务创建接口绕过审批。
- 日期任务写入`scheduledAt`与`visibleAfter`；只有日期而没有时间时沿用未来单次任务规则，在计划日`00:00`释放。任务可同时关联盒子、设备、主线、支线和里程碑。
- 执行方式使用`self / ai / hybrid`。`ai`任务通过共享数据进入人生参谋部 AI 作战区，不额外复制任务。
- 只有用户明确指定“唯一主动作”或“维护动作”时，任务中枢才把任务 ID 额外写入`POST /v1/hq/daily-briefs/:date`；普通待办不得占用驾驶舱名额。
- 写入使用确定性`syncKey`和内容、日期、盒子的联合去重。重复任务更新执行属性或驾驶舱角色，不生成副本。
- 本机桥接实现位于`D:\note_new\06-日常输入_输出\.agents\skills\任务中枢\scripts\task_hub_bridge.py`，认证沿用私有 Token 文件或`TASKBOX_API_TOKEN`，凭据不进入仓库。

实现细节见 `docs/architecture.md`，部署与恢复见 `docs/runbook.md`。

## 12. 当前实现与下一阶段边界

截至 2026-08-09，今日驾驶舱 P1 已完成生产发布：`hq_daily_briefs.primaryTaskId`继续保存原始战略承诺，`currentActionTaskId`保存当前行动席位，完成任务退出席位并以`completionReceipt`进入今日战果。P0 的同步保护继续有效，P1 的全量测试、构建、API 集成测试与线上字段探针均已通过。

- 原始战略承诺与动态“当前行动席位”分离。
- 主动作完成后进入今日战果，并由用户确认接棒动作。
- 基于资格门槛和可解释投产比的候选排序。
- 子系统事实 → 信号 → 行动候选 → TaskBox → 完成证据的统一闭环。
- `js/hq-systems.js`维护轻量`system_registry`；L0 只提供入口，L1 只读事实，L2 仅在用户确认后受控写回。

唯一规划文档为`docs/hq-primary-action-system-loop-v2.md`。P1–P3 已完成生产发布；P4 提案控制平面和审批 UI 已于 2026-08-10 进入代码，前端 Build ID`1962464071d3`已生产，API/schema 尚待生产发布。只有批准日动作可以 promotion，周省实验和月省押注保持战略对象，月度 provisional 证据禁止批准。
